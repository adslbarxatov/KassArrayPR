- Реализована возможность хранения внешнего файла-списка пользователей, общего для нескольких рабочих мест. В настройках может быть задан сетевой или общедоступный путь, к которому можно привязать все необходимые рабочие места. Обновление списка происходит при отправке заявления на печать;

- Удалены неиспользуемые настройки приложения;
- Обновлены пакеты поддержки `.NET`;
- Добавлен поиск ранее сохранённых данных пользователя по фрагменту его наименования;
- При получении данных регистрации из ФН остальные реквизиты пользователя (ОГРН, КПП и прочие) будут автоматически подставлены в соответствующие поля заявления, если этот пользователь имеется среди ранее сохранённых
